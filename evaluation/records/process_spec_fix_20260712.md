# process_spec 修正清单(境外题必需类目)· 2026-07-12

**原则**(用户定):数据集按**具体工具**构造——境外(美国)题的正解链路是 yelp_agent(商户评价,返回含地址/坐标)+ caiyun(天气,按经纬度)+ climatiq(碳排放);高德系工具不覆盖境外,'地理编码/路线规划/POI搜索/IP定位'等类目在 TOOL2CAT 里只有高德工具能满足,写进境外题的必需类目 = 正确行为永远拿不到的死分。

## 追加:工具尺度依赖对审计(2026-07-13,用户定义澄清后)

**定义澄清(数据集作者)**:顺序依赖 = **工具尺度**——后一工具的**输入**依赖前一工具的**输出**;题面叙事词("然后")不构成依赖。据此全库审计 25 种依赖对模式(~160 对):

| 查询 | 修改 | 理由 |
|---|---|---|
| SD-50 | 删 `路线规划→天气` | 天气输入=起点(石家庄)坐标(checklist SD-50.6),不消费路线输出 |
| SD-04 | `路线规划→天气` → `地理编码→天气` | 天气目标=南京到达当天,输入=南京坐标,与路线输出无关 |
| SD-06 | **保留** `距离测量→天气` | "更近那家有没有下雨":天气地点选择真依赖距离测量输出,合法 I/O 依赖 |

其余模式全部通过工具尺度检验。agent 侧同步:planner 撤销"叙事顺序词编码为依赖"规则,改为明确"depends_on 只编码数据依赖"。
